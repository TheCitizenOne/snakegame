# Snake Game
A simple, terminal based snake game. Written in Python, for educational reasons. So please don't wait any future update so soon.

![Screenshot from 2025-05-02 23-32-02](https://github.com/user-attachments/assets/9916f6e4-1703-4a5c-bbe8-7401149584be)

# Gameplay
- `w` for up
- `s` for down
- `a` for left
- `d` for right
- `p` for pause the game
- `q` for quit the game

# Requirements
- curses
- time
- random

# Usage
Type `python snakegame.py` to terminal in the directory of game for start it.
